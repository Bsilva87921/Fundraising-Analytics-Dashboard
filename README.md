# Fundraising Analytics Executive Dashboard

## Project Overview

Fundraising Dashboard Overview.PNG

This Power BI dashboard analyzes nonprofit fundraising performance using donor and giving data.

## Key Metrics

- Total Donations
- Total Donors
- Average Gift

## Dashboard Features

- Donation Trends by Year
- Revenue by Designation
- Revenue by Gift Type
- Top Donor Analysis
- Interactive Filters
- Executive Recommendations

## Key Insights

- Alumni Association generated the highest donation revenue.
- Credit Card and Stock gifts generated significant revenue.
- Fundraising revenue increased significantly in recent years.
- Major donors contribute a meaningful share of total fundraising revenue.

## Strategic Recommendations

1. Expand alumni-focused fundraising initiatives.
2. Increase investment in digital giving channels.
3. Strengthen major donor stewardship.
4. Develop donor retention programs.
